# 📅 Interactive Calendar Component

## 🚀 Overview
This project is a modern, interactive wall-style calendar built using Next.js and Tailwind CSS. It replicates a physical calendar UI with added interactivity like date range selection and persistent notes.

---

## ✨ Features

- 📸 Wall calendar aesthetic with hero image
- 📅 Real calendar with correct weekdays alignment
- 🔁 Month navigation (Next / Previous)
- 📍 Date range selection (start → end highlighting)
- 📝 Notes section with localStorage persistence
- 📱 Fully responsive design
